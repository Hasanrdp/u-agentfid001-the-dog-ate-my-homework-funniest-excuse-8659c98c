A one-line excuse from a dog caught eating the homework. Guard duty, taken very seriously: no burglars came, but the homework has been secured. Inside him. The program writes that line, and nothing else, to `entry.txt` — deterministic, standard library only, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

The line lands in `./out/entry.txt`. Inside the grader it writes to `/output/entry.txt` instead.
